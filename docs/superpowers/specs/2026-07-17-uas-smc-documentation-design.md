# UAS-SMC 仿真与理论文档设计规格

## 1. 目标

为当前 MATLAB 倒立摆 UAS-SMC 项目生成三份可独立阅读、相互引用的中文 Markdown 文档：

1. `docs/01_仿真使用说明.md`：说明项目文件、输出结果和运行方式。
2. `docs/02_UAS-SMC理论推导.md`：从倒立摆状态模型推导当前代码实际采用的虚拟状态、切换面、辅助面、趋近律和控制律。
3. `docs/03_UAS-SMC稳定性证明.md`：给出理想连续未饱和闭环的严格稳定性论证，并明确数字采样和输入饱和下的结论边界。

## 2. 事实来源与优先级

文档按以下优先级处理可能不一致的符号或参数：

1. MATLAB 实现与已保存的 MAT 结果决定“当前实际采用了什么”。
2. `uas-smc.pdf` 的式 (2.18) 至式 (2.57) 决定 UAS-SMC 理论结构与定理来源。
3. `倒立摆状态模型-完整版.pdf` 决定物理参数、线性化模型与电机模型的来源。
4. `推导手稿/page1.jpg`、`推导手稿/page2.jpg` 用于核对针对本倒立摆模型的中间推导。

所有重要公式均注明其是“资料原式”“针对本模型的变换”还是“当前代码定义”。不把仿真验证表述为数学证明。

## 3. 文档一：仿真使用说明

### 3.1 内容范围

- 项目目标、状态变量顺序、采样周期 `0.005 s` 和仿真频率 `200 Hz`。
- 四个 MATLAB 文件的职责、输入输出及调用关系：
  - `uas_smc_controller.m`
  - `run_uas_smc_sim.m`
  - `optimize_uas_smc.m`
  - `test_uas_smc.m`
- `results` 目录中每个 MAT/PNG 文件的含义。
- 基线仿真、优化参数仿真、重新优化和运行测试的准确 MATLAB 命令。
- `simulation_options` 与 `optimizer_options` 的常用覆盖示例。
- 当前优化结果摘要及结果判定阈值。

### 3.2 使用体验

读者无需阅读源码即可完成以下操作：

1. 运行现有优化控制器的标准仿真。
2. 切换到基线控制器。
3. 修改初始摆角、仿真时长和输出目录。
4. 重新执行参数优化。
5. 运行全部自动化测试并定位生成的图和数据。

## 4. 文档二：理论推导

### 4.1 推导顺序

1. 定义状态向量
   \(x=[p,\dot p,\theta,\dot\theta]^\mathsf T\) 和输入电枢电压 \(u_a\)。
2. 根据物理参数给出小角度线性模型
   \(\dot x=Ax+Bu\)，列出符号矩阵结构、参数公式和当前数值矩阵。
3. 说明单输入欠驱动系统不采用两个物理输出通道的直接求逆。
4. 利用可控标准形构造标量虚拟状态 \(\sigma=Sx\)，令 \(SB=1\)，并通过三个指定负极点保证零动态稳定。
5. 定义积分状态 \(\eta=\int_0^t\sigma(\tau)d\tau\)。
6. 定义两条切换面
   \(s_1=\sigma+\xi_1\eta\)、\(s_2=\sigma+\xi_2\eta\)，其中 \(\xi_1>\xi_2>0\)。
7. 按 \((s_1,s_2)\) 的符号划分四个子空间，给出四条辅助面
   \(h_i=\omega_{i1}\sigma+\omega_{i2}\eta+m\)。
8. 给出连续混合系数 \(\varepsilon\) 的分段定义。
9. 给出当前式 (2.57) 型连续趋近项
   \[
   \phi=\varepsilon(a\sigma-ks_2)
   +(1-\varepsilon)\frac{a+b}{2}\sigma,
   \]
   以及检验量
   \(N=\omega_2\sigma+\omega_1\phi\)。
10. 由 \(\dot\sigma=SAx+SBu\) 解出未饱和控制律
    \[
    u^*=\frac{-SAx+\phi}{SB},
    \]
    再说明代码中的 \(\pm12\,\mathrm V\) 饱和。
11. 列出基线参数和优化参数，解释优化变量与实际控制参数的映射。

### 4.2 图与代码映射

理论文档引用现有相平面图和诊断图，并用表格把每个数学符号映射到 MATLAB 字段，例如 `sigma`、`s1`、`s2`、`epsilon`、`phi`、`N`、`h` 和 `region`。

## 5. 文档三：稳定性证明

### 5.1 证明范围

严格证明针对以下理想条件：

- 连续时间线性模型准确；
- 全状态可用；
- 控制输入未触发饱和，即 \(u=u^*\)；
- 参数满足 UAS-SMC 对称辅助面和趋近律条件；
- 当前构造满足 \(SB\ne0\)，且零动态矩阵 Hurwitz。

### 5.2 分层证明结构

1. **虚拟子系统闭环化**：代入控制律证明 \(\dot\sigma=\phi\)、\(\dot\eta=\sigma\)。
2. **辅助面单向性**：对当前激活面证明
   \(\dot h_i=\omega_{i1}\dot\sigma+\omega_{i2}\dot\eta=N_i\ge0\)，并说明等号集合。
3. **趋近正不变集并保持**：结合四个区域的几何方向和辅助面偏置说明轨迹趋近包含原点的正不变集；一旦进入便不会离开。现有条件不额外声称有限到达时间。
4. **虚拟状态收敛**：依据论文定理和 LaSalle 型不变性论证，最大不变零集为 \((\sigma,\eta)=(0,0)\)，因此两者渐近收敛。
5. **内部动态稳定**：在可控标准形中分离 \(\sigma\) 与三维内部状态，利用所选内部极点均位于左半平面，证明 \(\sigma\to0\) 时内部状态趋于零，从而原四维状态 \(x\to0\)。

### 5.3 采样和饱和边界

文档不声称当前数字闭环全局渐近稳定。对以下两点分别说明：

- `Ts=0.005 s` 的零阶保持仿真是连续理想控制器的数值实现，严格采样稳定性还需要离散 Lyapunov 或 ISS 误差界。
- 当 \(|u^*|>12 V\) 时，\(\dot\sigma=\phi\) 不再精确成立；严格结论只能限制在不触发饱和的区域，或表述为基于当前测试范围的实用稳定性证据。

最后列出当前仿真的峰值电压、收敛时间、训练与验证通过率，明确这些是数值证据而非证明。

## 6. 格式与质量要求

- 使用 GitHub Markdown 与 LaTeX 数学公式。
- 每份文档开头注明适用代码版本和资料来源。
- 参数、矩阵、文件名和结果数值从代码或 MAT 文件读取并交叉核对。
- 本地文件使用相对链接，保证整个目录移动后仍可访问。
- 不保留待填写占位符、未定义符号或无法复现的命令。
- 稳定性文档显式区分定理、假设、证明和工程解释。

## 7. 验收标准

1. 三个目标 Markdown 文件均存在，且互相引用有效。
2. 所有 MATLAB 文件和结果文件的说明与当前目录一致。
3. 文档中的 \(A\)、\(B\)、\(S\)、控制参数和性能结果与 MAT 文件一致。
4. 相平面中的六条直线公式与绘图代码一致。
5. 理想连续证明不错误扩展到输入饱和或采样闭环。
6. 所有运行命令可由 MATLAB R2025a 在项目根目录执行。
