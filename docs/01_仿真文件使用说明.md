# UAS-SMC 倒立摆仿真文件使用说明

本文说明当前仓库中各 MATLAB 文件的职责、运行方法、输入输出及适用边界。理论细节分别见[虚拟状态整体设计](02_虚拟状态整体设计与推导.md)和[UAS-SMC 设计与参数优化](03_UAS-SMC设计与参数优化.md)，已有结果的解读见[仿真结果分析](04_仿真结果分析.md)。

## 1. 仿真对象与默认条件

仓库仿真的是直线倒立摆在直立平衡点附近的小角度线性模型：

$$
\dot{x}=Ax+Bu,
\qquad
x=\begin{bmatrix}p&\dot p&\theta&\dot\theta\end{bmatrix}^{\mathsf T},
$$

其中 $p$ 为小车位置，$\theta$ 为相对直立位置的摆角，$u$ 为电机电枢电压。默认配置为：

| 项目 | 默认值 |
|---|---:|
| 采样周期 | $T_s=0.005\,\mathrm{s}$ |
| 仿真频率 | $200\,\mathrm{Hz}$ |
| 仿真时长 | $8\,\mathrm{s}$ |
| 初始状态 | $[0,0,5^\circ,0]^{\mathsf T}$ |
| 虚拟积分初值 | $\eta(0)=0$ |
| 电压限制 | $-12\,\mathrm{V}\le u\le12\,\mathrm{V}$ |
| 默认控制器 | `results/uas_smc_best_params.mat` 中的优化参数 |

该模型用于小角度稳摆，不包含摆杆从下垂位置起摆的能量控制，也不是非线性实物模型。

## 2. 文件职责

### 2.1 可直接运行的脚本

| 文件 | 作用 | 运行时机 | 主要输出 |
|---|---|---|---|
| [`run_uas_smc_sim.m`](../run_uas_smc_sim.m) | 建立名义模型，分别仿真基线控制器和选定控制器，计算指标并生成图 | 日常运行、修改控制器后复核 | 工作区变量 `sim_results`、5 张响应图、`uas_smc_results.mat` |
| [`optimize_uas_smc.m`](../optimize_uas_smc.m) | 在多初值和参数摄动工况下执行粒子群优化与局部搜索 | 需要重新整定参数时 | `best_ctrl`、`optimization_report`、最优参数与收敛图 |
| [`test_uas_smc.m`](../test_uas_smc.m) | 执行模型、几何、连续性、对称工况、优化器和正式结果的回归测试 | 修改代码、参数或结果文件后 | MATLAB `TestResult` 数组 |

### 2.2 被其他脚本调用的函数

| 文件 | 作用 | 是否应单独运行 |
|---|---|---|
| [`uas_smc_controller.m`](../uas_smc_controller.m) | 在一个采样时刻计算 $\sigma$、$s_1$、$s_2$、$\varepsilon$、$\phi$、$N$、激活辅助面和控制电压 | 否，由仿真器或测试调用 |
| [`uas_smc_auxiliary_geometry.m`](../uas_smc_auxiliary_geometry.m) | 根据 $\xi_1$、$\xi_2$、$\beta$ 和 $m_h$ 统一生成辅助面系数、正不变集顶点及切换面残差 | 否，由控制器、绘图、优化器和测试共同调用 |

共用几何函数很重要：它避免控制器、优化器和相平面绘图各自使用不同的辅助面参数。

## 3. 环境要求

当前仓库已在 MATLAB R2025a 下运行。脚本使用 `tiledlayout`、`exportgraphics`、`functiontests`、`expm` 等 MATLAB 功能；优化器本身没有调用 Global Optimization Toolbox 的 `particleswarm`，而是在脚本中直接实现粒子群迭代。

建议从仓库根目录运行：

```matlab
cd('D:\inverted pendulum\UAS-SMC');
```

## 4. 标准仿真怎么运行

### 4.1 使用已保存的优化参数

```matlab
cd('D:\inverted pendulum\UAS-SMC');
clear simulation_options;
run('run_uas_smc_sim.m');
```

默认会执行以下操作：

1. 建立名义倒立摆模型并检查可控性；
2. 从 `results/uas_smc_best_params.mat` 读取 `best_ctrl`；
3. 仿真一次基线控制器和一次优化控制器；
4. 将优化控制器的结果作为 `sim_results.selected`；
5. 生成 5 张结果图并保存 `results/uas_smc_results.mat`；
6. 在命令窗口打印内部极点、控制参数和主要性能指标。

若参数文件不存在，脚本会报出 `uas_smc:MissingOptimizedParameters`。此时可以先运行优化器，也可以关闭 `useOptimized`。

### 4.2 只运行基线控制器且不覆盖正式结果

```matlab
simulation_options = struct( ...
    'useOptimized', false, ...
    'makePlots', true, ...
    'saveResults', false, ...
    'figureVisible', 'on');
run('run_uas_smc_sim.m');
```

基线参数为内部极点 $[-2,-3,-4]$、$\xi_1=2$、$\xi_2=1$、$\beta=1$、$k=4$。该运行适合判断优化前后的差异。

### 4.3 修改初始状态

例如测试 $-8^\circ$ 初始摆角：

```matlab
simulation_options = struct( ...
    'x0', [0; 0; deg2rad(-8); 0], ...
    'useOptimized', true, ...
    'saveResults', false, ...
    'figureVisible', 'on');
run('run_uas_smc_sim.m');
```

`x0` 必须按 $[p,\dot p,\theta,\dot\theta]^{\mathsf T}$ 排列，角度单位必须是弧度。

### 4.4 使用自定义控制参数

```matlab
custom_ctrl = struct( ...
    'poles', [3 7 11], ...
    'xi1', 12, ...
    'xi2', 3, ...
    'beta', 4, ...
    'k', 12, ...
    'm_aux', 0.01, ...
    'u_max', 12, ...
    'tol', 1e-12);

simulation_options = struct( ...
    'ctrl', custom_ctrl, ...
    'saveResults', false, ...
    'figureVisible', 'on');
run('run_uas_smc_sim.m');
```

必须满足

$$
0<p_1<p_2<p_3,
\qquad
\xi_1>\xi_2>0,
\qquad
\beta>0,
\qquad
k>0.
$$

$\alpha$ 和辅助面缩放量 $\lambda$ 是由几何约束计算出的派生量，不应作为独立参数传入。

## 5. `simulation_options` 配置项

| 字段 | 默认值 | 作用 |
|---|---:|---|
| `Ts` | `0.005` | 采样周期，单位 s |
| `Tend` | `8` | 仿真终止时间，单位 s |
| `x0` | `[0;0;deg2rad(5);0]` | 四维物理状态初值 |
| `eta0` | `0` | $\eta=\int\sigma\,dt$ 的初值 |
| `useOptimized` | `true` | `ctrl` 为空时是否读取优化参数 |
| `ctrl` | `[]` | 调用者指定的控制器；非空时优先级最高 |
| `modelParams` | `struct()` | 覆盖一个或多个名义物理参数 |
| `makePlots` | `true` | 是否要求生成绘图对象 |
| `saveResults` | `true` | 是否输出 PNG 和 MAT 文件 |
| `verbose` | `true` | 是否打印结果摘要 |
| `figureVisible` | `'off'` | 图窗为 `'on'` 或 `'off'` |
| `outputDir` | 根目录下的 `results` | 参数读取目录和结果输出目录 |

注意以下细节：

- 多次运行不同配置前应执行 `clear simulation_options`，否则上次设置会保留在工作区。
- `ctrl` 非空时，`useOptimized` 不再决定控制器来源。
- `useOptimized=true` 时，参数文件也从 `outputDir` 中读取。若把输出目录改成新目录，该目录必须已有 `uas_smc_best_params.mat`。
- 只要 `makePlots` 或 `saveResults` 有一个为 `true`，脚本就会创建图形；当 `figureVisible='off'` 时，保存后图窗会关闭。
- `saveResults=true` 会覆盖输出目录下同名的正式结果文件。探索性运行建议设为 `false` 或使用独立目录。

## 6. 数值仿真是怎样推进的

标准仿真没有使用 `ode45`。脚本先对增广状态

$$
z_a=\begin{bmatrix}x^{\mathsf T}&\eta\end{bmatrix}^{\mathsf T}
$$

构造

$$
\dot z_a=
\begin{bmatrix}A&0\\S&0\end{bmatrix}z_a+
\begin{bmatrix}B\\0\end{bmatrix}u,
$$

再用矩阵指数计算采样周期 $T_s$ 下的精确零阶保持矩阵。每个采样点执行：

1. 根据当前 $x_k$ 和 $\eta_k$ 计算一次控制量 $u_k$；
2. 在 $[kT_s,(k+1)T_s)$ 内保持 $u_k$ 不变；
3. 用精确离散矩阵推进到下一采样点。

因此，“精确”只指常值输入下线性模型的区间传播，不表示控制器在采样间隔内连续更新。

## 7. 参数优化怎么运行

### 7.1 完整优化

```matlab
clear optimizer_options;
run('optimize_uas_smc.m');
```

默认执行 40 个粒子、60 轮 PSO 和最多 100 轮局部坐标搜索。训练集包含 4 个名义固定初始角和 12 个随机摄动工况，随后用 100 个独立随机工况验证。完整运行会覆盖：

- `results/uas_smc_best_params.mat`；
- `results/optimization_history.mat`；
- `results/optimization_convergence.png`。

优化结束后应再运行一次 `run_uas_smc_sim.m`，使标准响应图与新参数保持一致。

### 7.2 快速流程检查

```matlab
optimizer_options = struct( ...
    'particles', 8, ...
    'iterations', 3, ...
    'trainingRandomCount', 2, ...
    'validationCount', 10, ...
    'localMaxRounds', 3, ...
    'saveResults', false, ...
    'verbose', true);
run('optimize_uas_smc.m');
```

该配置只用于检查流程和接口，不足以替代仓库内保存的正式优化结果。

## 8. 自动化测试

在 MATLAB 中运行：

```matlab
r = runtests('test_uas_smc.m');
table(r)
assertSuccess(r);
```

或从 PowerShell 运行：

```powershell
& 'D:\matlab\matlabr2025a\bin\matlab.exe' -batch "r=runtests('test_uas_smc.m'); assertSuccess(r);"
```

当前 10 项测试覆盖：

- 必需实现文件是否存在；
- 辅助面顶点是否落在指定切换面上；
- 原点平衡、控制器奇对称性和网格上的 $N\ge-10^{-9}$；
- 切换边界附近的 $\phi$ 连续性；
- 名义模型矩阵、可控性、内部极点和 $SB=1$；
- $\pm5^\circ$、$\pm8^\circ$ 对称工况；
- 快速优化器约束及“不劣于基线”条件；
- 相平面图、趋近律图和 $\dot N$ 数值计算；
- 正式优化参数、训练/验证结果和全部输出文件。

## 9. 输出文件与读取方法

`results` 中的文件分为三类：

| 类别 | 文件 |
|---|---|
| 参数与优化记录 | `uas_smc_best_params.mat`、`optimization_history.mat`、`optimization_convergence.png` |
| 标准仿真数据 | `uas_smc_results.mat` |
| 标准仿真图片 | `uas_smc_response.png`、`uas_smc_diagnostics.png`、`baseline_vs_optimized.png`、`uas_smc_phase_plane.png`、`uas_smc_reaching_law.png` |

读取标准结果：

```matlab
data = load('results/uas_smc_results.mat');
r = data.sim_results;

time = r.selected.t;
state = r.selected.state;
eta = r.selected.eta;
voltage = r.selected.u;
diagnostic = r.selected.diagnostic;
metrics = r.selected.metrics;
```

`state` 的四列依次为 $p$、$\dot p$、$\theta$、$\dot\theta$。`diagnostic` 中的重要字段为：

| 字段 | 数学量 | 作用 |
|---|---|---|
| `sigma` | $\sigma$ | 标量虚拟状态 |
| `s1`, `s2` | $s_1,s_2$ | 两条切换面函数值 |
| `epsilon` | $\varepsilon$ | 连续混合系数 |
| `phi` | $\phi$ | 未饱和时的期望 $\dot\sigma$ |
| `N` | $N$ | 当前激活辅助面的理论导数 |
| `N_dot` | 数值 $\dot N$ | 仿真后用 `gradient` 计算，仅用于观察 |
| `h` | $h$ | 当前区域的激活辅助面函数值 |
| `region` | $0,1,2,3$ | 当前子空间编号 |
| `u_unsat` | $u^*$ | 限幅前的控制需求 |
| `saturated` | 饱和标志 | 判断 $\lvert u^*\rvert>u_{\max}$ |

每个结果文件的具体用途和当前数值见[仿真结果分析](04_仿真结果分析.md)。

## 10. 推荐工作流

修改模型、控制器或优化器后，建议依次执行：

1. 用 `saveResults=false` 运行单个自定义工况；
2. 运行 `test_uas_smc.m`；
3. 若改变了待优化参数或目标函数，重新运行 `optimize_uas_smc.m`；
4. 运行默认 `run_uas_smc_sim.m` 更新正式 MAT 和 PNG；
5. 再次运行全部测试，并检查相平面图和优化收敛图。

## 11. 结论边界

当前脚本证明或验证的是 MATLAB 中的小角度线性模型。它没有提供以下结论：

- 任意大角度下的全局稳定性；
- 采样、饱和和参数不确定性下的统一严格稳定性证明；
- 传感器噪声、量化、时延和执行器死区下的硬件性能；
- 实机部署或起摆控制已经完成。

标准仿真、随机验证和自动化测试是数值证据，不能替代上述额外理论证明或硬件验证。
