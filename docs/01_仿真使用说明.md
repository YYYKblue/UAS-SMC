# UAS-SMC 倒立摆 MATLAB 仿真使用说明

> 适用版本：2026-07-17 当前工作区。本文以实际 MATLAB 源码和 `results` 中已保存的数据为准。

相关文档：[控制理论推导](02_UAS-SMC理论推导.md)｜[稳定性证明](03_UAS-SMC稳定性证明.md)

## 1. 项目目标与适用范围

本项目在 MATLAB 中仿真直线倒立摆的小角度线性化模型，并使用连续无抖振单向辅助滑模控制（UAS-SMC）实现：

- 小车初始位置为原点；
- 摆杆存在小角度初始偏差；
- 小车位置和摆杆角度最终回到原点；
- 采样周期为 `0.005 s`，即仿真频率为 `200 Hz`；
- 电机电枢电压限制为 `[-12,12] V`。

默认初始状态为

$$
x(0)=\begin{bmatrix}0&0&5^\circ&0\end{bmatrix}^{\mathsf T},
$$

状态顺序固定为：

$$
x=\begin{bmatrix}p&\dot p&\theta&\dot\theta\end{bmatrix}^{\mathsf T},
$$

其中 $p$ 为小车位置，$\theta$ 为相对直立平衡点的摆角。

本项目只验证直立点附近的小角度稳摆，不包含从下垂位置起摆的能量控制。

## 3. 快速运行

### 3.1 运行现有优化控制器

在 MATLAB 命令窗口中执行：

```matlab
cd('D:\inverted pendulum\UAS-SMC');
clear simulation_options;
run('run_uas_smc_sim.m');
```

脚本默认：

- 从 `results/uas_smc_best_params.mat` 读取优化参数；
- 仿真 `8 s`；
- 使用 `Ts=0.005 s`；
- 初始摆角为 `5 deg`；
- 图窗不显示，但 PNG 和 MAT 会保存到 `results`；
- 在命令窗口打印主要性能指标。

运行结束后，当前 MATLAB 工作区中会出现 `sim_results`。

### 3.2 运行基线控制器

```matlab
simulation_options = struct( ...
    'useOptimized', false, ...
    'makePlots', true, ...
    'saveResults', false, ...
    'figureVisible', 'on');
run('run_uas_smc_sim.m');
```

该方式不读取优化参数，也不会覆盖 `results` 中的正式结果。

## 4. 仿真配置

### 4.1 可用的 `simulation_options`

| 字段 | 默认值 | 含义 |
|---|---:|---|
| `Ts` | `0.005` | 采样周期，单位 s |
| `Tend` | `8` | 仿真终止时间，单位 s |
| `x0` | `[0;0;deg2rad(5);0]` | 四维初始状态 |
| `eta0` | `0` | $\eta=\int\sigma dt$ 的初值 |
| `useOptimized` | `true` | 是否读取优化参数 |
| `ctrl` | `[]` | 非空时优先使用调用者提供的控制参数 |
| `modelParams` | `struct()` | 覆盖物理参数 |
| `makePlots` | `true` | 是否保留生成的 MATLAB 图窗 |
| `saveResults` | `true` | 是否保存 PNG 和 MAT |
| `verbose` | `true` | 是否打印性能摘要 |
| `figureVisible` | `'off'` | 图窗可见性 |
| `outputDir` | `results` | 参数读取与结果输出目录 |

脚本会把调用者提供的字段覆盖到默认值上。多次运行不同配置前，建议先执行 `clear simulation_options`，避免上一次结构继续生效。

### 4.2 修改初始摆角

例如仿真初始摆角为 $-8^\circ$：

```matlab
simulation_options = struct( ...
    'x0', [0; 0; deg2rad(-8); 0], ...
    'useOptimized', true, ...
    'makePlots', true, ...
    'saveResults', false, ...
    'figureVisible', 'on');
run('run_uas_smc_sim.m');
```

### 4.3 修改仿真时长和输出目录

```matlab
simulation_options = struct( ...
    'Tend', 10, ...
    'outputDir', fullfile(pwd, 'results_custom'), ...
    'useOptimized', false, ...
    'saveResults', true);
run('run_uas_smc_sim.m');
```

注意：`useOptimized=true` 时，脚本会从 `outputDir` 中读取 `uas_smc_best_params.mat`。若新目录中没有该文件，应先设置 `useOptimized=false`，或者把参数文件复制到新目录。

### 4.4 使用自定义控制参数

```matlab
custom_ctrl = struct( ...
    'poles', [3 7 11], ...
    'xi1', 12, ...
    'xi2', 3, ...
    'beta', 4, ...
    'k', 12, ...
    'm_aux', 0.01, ...
    'u_max', 12, ...
    'tol', 1e-12);

simulation_options = struct( ...
    'ctrl', custom_ctrl, ...
    'useOptimized', false, ...
    'saveResults', false, ...
    'figureVisible', 'on');
run('run_uas_smc_sim.m');
```

必须满足：

$$
p_1<p_2<p_3,qquad p_i>0,qquad
\xi_1>\xi_2>0,qquad \beta>0,\qquad k>0.
$$

`alpha` 不再是独立输入。程序根据 `xi1`、`xi2` 和 `beta` 自动计算 `alpha` 及辅助面尺度，使四个辅助面顶点严格位于两条切换面上；调用者提供的旧 `alpha` 字段会被规范化结果覆盖。

## 5. 参数优化

### 5.1 运行完整优化

```matlab
cd('D:\inverted pendulum\UAS-SMC');
clear optimizer_options;
run('optimize_uas_smc.m');
```

默认优化配置包括：

- 40 个粒子；
- 60 轮 PSO；
- 100 轮以内的局部坐标搜索；
- 4 个固定初始角工况和 12 个随机训练工况；
- 100 个随机参数摄动验证工况；
- 物理参数在名义值的 $\pm10\%$ 内随机变化；
- 初始摆角在 $[-8^\circ,8^\circ]$ 内变化；
- 固定随机种子，结果可复现。

优化耗时明显长于单次仿真。完成后会覆盖 `results/uas_smc_best_params.mat` 和优化历史，然后应再次运行标准仿真更新正式结果图。

### 5.2 快速试运行优化器

```matlab
optimizer_options = struct( ...
    'particles', 8, ...
    'iterations', 3, ...
    'trainingRandomCount', 2, ...
    'validationCount', 10, ...
    'localMaxRounds', 3, ...
    'saveResults', false, ...
    'verbose', true);
run('optimize_uas_smc.m');
```

快速配置只适合检查优化流程，不能替代正式优化结果。

### 6.1 读取仿真结果

```matlab
data = load('results/uas_smc_results.mat');
r = data.sim_results;

A = r.model.A;
B = r.model.B;
time = r.selected.t;
state = r.selected.state;
voltage = r.selected.u;
metrics = r.selected.metrics;
```

主要结构：

| 路径 | 含义 |
|---|---|
| `sim_results.model` | 物理参数、$A$、$B$、可控矩阵等 |
| `sim_results.options` | 本次仿真配置 |
| `sim_results.baseline` | 基线控制器响应 |
| `sim_results.selected` | 实际选用控制器的响应 |
| `sim_results.ctrlBaseline` | 基线参数 |
| `sim_results.ctrlSelected` | 优化或调用者参数 |

`selected.state` 的列顺序为 $p,\dot p,\theta,\dot\theta$。诊断量位于 `selected.diagnostic`，包括：

```matlab
d = r.selected.diagnostic;
sigma = d.sigma;
s1 = d.s1;
s2 = d.s2;
epsilon = d.epsilon;
phi = d.phi;
N = d.N;
N_dot = d.N_dot;
h_active = d.h;
region = d.region;
```

`N_dot` 使用 MATLAB `gradient(N,Ts)` 计算：内部点为中心差分，两个端点为单边差分。它用于观察变化速度，不参与控制器计算。

## 9. 常见问题与限制

### 9.1 提示缺少优化参数

错误信息为 `Optimized parameters are missing` 时：

1. 运行 `optimize_uas_smc.m` 生成参数；或
2. 设置 `simulation_options.useOptimized=false`；或
3. 检查 `outputDir` 是否指向包含参数文件的目录。

### 9.2 为什么不直接分别控制小车和摆角

系统只有一个电压输入，不能独立求逆两个输出通道。当前实现先把四维状态映射为标量 $\sigma=Sx$，并通过 $S$ 的设计保证其余内部动态稳定。详见[理论推导](02_UAS-SMC理论推导.md)。

### 9.3 为什么仿真稳定不等于已经证明数字闭环全局稳定

论文理论针对连续理想控制。当前实现还包含 200 Hz 采样、零阶保持和电压饱和，因此严格证明必须区分条件。详见[稳定性证明](03_UAS-SMC稳定性证明.md)。

### 9.4 模型适用范围

模型来自直立点的小角度线性化。当前优化和测试把初始摆角限制在 $\pm8^\circ$，并以峰值不超过 $10^\circ$ 作为约束。这些范围是本项目的工程验证范围，不应外推到大角度起摆。
